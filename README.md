# Feature Engineering Strategy to Predict Central Neuropathic Pain
This repository contains a case study on predicting central neuropathic pain (CNP) in individuals with spinal cord injuries using EEG data. The project focuses on designing and evaluating various feature engineering and feature selection strategies, coupled with different machine learning classifiers. The ultimate goal is to determine which combination of techniques yields the most promising performance in terms of classification accuracy, sensitivity, and specificity.
